# Build and Upgrade Gemini FlowExecute these steps sequentially so existing working modules stay intact while broken audio, noise, and latency layers are replaced.## Step 1: Audit Existing Repository (Read-Only First)1. Inspect the project tree, runtime framework, dependencies, and existing audio, transcription, LLM, and UI files.2. Locate and map the exact interfaces of the three **working** modules that MUST NOT be broken:   - Quick Text / Snippets   - Custom Dictionary   - Custom Directory / Local Storage3. List every current failure point (e.g., `MediaRecorder` usage, `ScriptProcessorNode`, missing 16 kHz PCM16 resampling, missing RNNoise/Silero VAD, `store: true` or thinking-enabled LLM calls, or missing OS paste hooks).4. Present the audit summary and file-by-file plan before editing code.## Step 2: Implement Stage 1 & Stage 2 (AudioWorklet + RNNoise + Silero VAD)1. Build an `AudioWorklet` processor running on the audio thread that applies optional Whisper Mode gain, downsamples mic input to 16,000 Hz mono `Int16Array` (PCM16), and emits 20–40 ms frames.2. Integrate RNNoise WASM noise suppression and Silero VAD turn detection with a pre-speech ring buffer and ~120 ms end-of-turn hangover.3. Add pause-based clause slicing for long dictations and rolling local audio persistence for crash recovery.## Step 3: Implement Stage 3 (Low-Latency ASR Provider Layer)1. Build an interchangeable `ASRService` supporting streaming WebSocket ASR (Deepgram Nova-3), fast clause-sliced batch ASR (Groq `whisper-large-v3-turbo`), and an optional local offline fallback (`faster-whisper-large-v3-turbo`).2. Wire the existing Custom Dictionary module into ASR keyword biasing and prompt hints.## Step 4: Implement Stage 4 (Stateless Gemini Cleanup & Formatting)1. Refactor the LLM post-processor to use a fast Gemini model with `store: false`, thinking disabled, persistent HTTP connections, and a safe raw-transcript fallback timeout.2. Implement the structured prompt covering Auto Cleanup levels (`none`, `light`, `medium`), Backtrack resolution, Smart Lists, Spoken Punctuation, App-Aware Styles, Code/Terminal bypass, optional `translate_target`, and `uncertain_spans` output.3. Persist both `raw_transcript` and `cleaned_text` through the existing Custom Directory module to support Undo AI Edit.## Step 5: Implement Stage 5 (Floating HUD, Accessibility Context & OS Paste)1. Build or update the always-on-top floating HUD pill with live waveform, clear mic error diagnostics, and uncertainty span indicators.2. Connect OS Accessibility inspection (excluding password fields) for active app classification, surrounding text, and IDE variable/filename context.3. Implement clipboard snapshot -> paste-at-cursor -> clipboard restore, Command Mode voice editing, and the Paste Last Transcript fallback hotkey.## Step 6: End-to-End Verification Checklist1. Verify unplugged or permission-blocked microphone errors display clear recovery guidance.2. Verify RNNoise + Silero VAD suppress room noise and prevent silence hallucinations.3. Test a spoken sentence with fillers and a Backtrack ("Let's meet Tuesday um actually Wednesday at 4 PM") and confirm clean paste-at-cursor with per-stage timing logs (`vad_end_ms`, `asr_final_ms`, `llm_done_ms`, `paste_done_ms`).4. Confirm Quick Text, Custom Dictionary, and Custom Directory continue passing all existing behaviors.
