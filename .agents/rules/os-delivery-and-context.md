# OS Layer, Context Awareness, Command Mode & IDE Integration## 1. Floating HUD Pill & Global Hotkeys- Render a compact, non-focus-stealing, always-on-top HUD pill showing: `idle`, `listening` (live mic waveform), `processing`, and clear diagnostic `error` states (e.g., mic unplugged, mic in use by another app, or blocked by OS permissions with fix instructions).- Register global OS hotkeys in the Electron main process (never renderer, to avoid macOS `uiohook-napi` deadlocks):  - **Hold Push-to-Talk:** Start on `keydown`, finalize on `keyup` (exempt modifier holds from OS key-repeat triggers).  - **Hands-Free Toggle:** Start on first press (supporting sessions up to 20 minutes), finalize on second press.  - **Command Mode Hotkey:** Capture highlighted text in any app and apply spoken editing instructions.  - **Paste Last Transcript Shortcut:** Global recovery shortcut (`Cmd+Ctrl+V` on macOS, `Shift+Alt+Z` on Windows) if target focus shifted before paste completed.## 2. Active App & Accessibility Context ReaderUse OS Accessibility APIs (macOS Accessibility / Windows UI Automation) and `get-windows` to read:- **Foreground App & Window/Tab Title:** Classify into `Personal` (Messages/WhatsApp), `Work` (Slack), `Email` (Gmail/Outlook), `Developer` (Cursor, VS Code, Windsurf, Terminals), or `Other`.- **Surrounding Text:** Read nearby text around the cursor to spell uncommon names accurately and check current-line punctuation.- **Strict Privacy Guardrail:** NEVER inspect or read password fields or secure OS inputs.## 3. Clipboard-Safe Paste-at-Cursor Delivery1. Snapshot current clipboard contents before pasting (with a short read timeout so slow source apps do not stall dictation; preserve text, links, and standard formats where available).2. Write `cleaned_text` (or rich-text HTML + plain text for Snippets) to the clipboard.3. Simulate OS paste (`Cmd+V` on macOS, `Ctrl+V` on Windows/Linux, `Ctrl+Shift+V` for terminals).4. Restore the prior clipboard snapshot after the target app reads the paste. If paste delivery fails or times out, leave the dictation on the clipboard and notify the user clearly.## 4. Command Mode & Voice TransformsWhen triggered via Command Mode:1. Capture the user's currently selected text via Accessibility (or temporary copy fallback).2. Capture the user's spoken instruction (e.g., "make this more concise", "reply declining politely", "turn into bullet points").3. Send `{ selected_text, voice_instruction, app_category }` to Gemini (`store: false`, thinking disabled).4. Replace the selection via clipboard-safe paste and tag the History row as a Command/Transform entry.## 5. Developer / Vibe Coding & Auto-Learning Dictionary- **IDE Context & File Tagging:** In VS Code, Cursor, and Windsurf, read visible editor symbols/filenames (when Screen Reader Accessibility Mode or tab metadata is available) and convert spoken AI-chat references like `"index dot ts"` or `"tag app dot tsx"` into `@index.ts` or `@app.tsx` when matching an open tab or sidebar file.- **AI Terminal Paste Safety:** When pasting multi-line dictations into AI coding terminals (e.g., Claude Code, Codex), ensure multi-line text stays visible and editable instead of collapsing or prematurely submitting.- **Auto-Learning Dictionary:** Detect quick post-paste manual word edits by the user and offer or auto-save corrected spellings into the existing Custom Dictionary module.
