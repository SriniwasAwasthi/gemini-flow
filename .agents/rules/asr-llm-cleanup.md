# ASR Routing & LLM Smart-Formatting Pipeline## 1. Interchangeable ASR Provider ArchitectureImplement a clean `ASRProvider` interface supporting three modes:1. **Streaming WebSocket Mode (Lowest Live Latency):** Deepgram Nova-3 (`encoding=linear16`, `sample_rate=16000`, `interim_results=true`, `smart_format=false` so our LLM controls formatting, and `keyterms` populated from Custom Dictionary).2. **Clause-Sliced Fast Batch Mode:** Groq `whisper-large-v3-turbo` (dispatch Silero-VAD-trimmed speech clauses as WAV/PCM segments; inject top Custom Dictionary terms into Whisper's `prompt` parameter).3. **Offline / Zero-Retention Fallback Mode:** Local `faster-whisper-large-v3-turbo` (`int8`) or NVIDIA Parakeet TDT (English) worker for offline use or strict privacy mode.## 2. Gemini Cleanup Latency Optimization (CRITICAL)- **Stateless Calls Only:** Every Gemini cleanup call MUST disable server-side conversation storage (`store: false`). Stateful `store=true` calls add multi-second latency penalties.- **Disable Thinking Mode:** Explicitly disable reasoning/thinking tokens on Gemini Flash / Flash-Lite models used for dictation cleanup to minimize time-to-first-token.- **Keep Connections Warm:** Reuse persistent HTTP/client connections in the main/backend process.- **Fail-Safe Timeout:** Enforce a tight cleanup timeout with automatic fallback to lightly punctuated `raw_transcript` so a slow network request never drops user speech.## 3. Exact Cleanup, Style, and Formatting RulesAccept structured context: `{ raw_transcript, cleanup_level, app_category, writing_style, surrounding_text, dictionary_terms, snippet_triggers, is_code_context, translate_target }`.### Auto Cleanup Levels- **`none`:** Bypass LLM rewriting and paste `raw_transcript` (applying only explicit Dictionary/Snippet matches if enabled).- **`light` (Default):** Remove filler words ("um", "uh", hesitation "like"), fix grammar/punctuation/capitalization, and resolve **Backtracks** while keeping the speaker's exact wording.- **`medium`:** Apply `light` cleanup plus concise editing for clarity and professional flow without changing facts, numbers, or intent.### Mandatory Smart Formatting Behaviors1. **Backtrack Self-Correction:** When the speaker changes their mind mid-utterance (e.g., "Let's meet at 2... actually 3", "Send to Alex, wait no, Priya"), output ONLY the corrected final statement.2. **Smart Bulleted & Numbered Lists:** When the speaker enumerates items ("one… two…", "first… second…"), strip the spoken sequence words where appropriate and format as a clean Markdown or rich-text bulleted/numbered list starting on a new line.3. **Spoken Punctuation & Paragraphing:** Honor spoken commands ("period", "comma", "question mark", "exclamation point", "colon", "semicolon", "em dash", "new line", "new paragraph") and spoken emoji names—unless context shows the speaker is talking *about* punctuation ("remove the comma"). Split long monologues into paragraphs at topic shifts.4. **App-Aware Writing Styles (English):**   - `Formal` (Docs, Work, Email default): Standard capitalization; always keep trailing periods.   - `Casual` (Messaging default, e.g., WhatsApp/Slack): Remove trailing periods on dictations of 10 sentences or fewer (unless ending with `!` or `?`, explicitly spoken, or the current line already contains terminal punctuation).   - `Very Casual`: Remove trailing periods across all dictations.   - `Excited`: Remove trailing periods only in messaging apps at 2 sentences or fewer; keep `!` and `?`.5. **Code & AI Terminal Bypass:** When `is_code_context` is true (VS Code, Cursor, Windsurf, Terminal, Claude Code, Codex), skip prose rewriting and casual period-stripping. Preserve `camelCase`, `snake_case`, CLI flags, URLs, ports, and file paths verbatim.6. **Multilingual & Optional Translation:** Preserve spoken languages and mid-sentence code-switching by default. Only translate output into another language when the user explicitly activates `translate_target`.7. **Uncertainty Tagging (Smarter-Than-Wispr):** Return `{ "cleaned_text": "...", "uncertain_spans": ["..."] }` so the floating HUD can highlight low-confidence proper nouns or homophones for one-click inspection.## 4. History & Undo AI Edit- Save `{ id, timestamp, app_name, raw_transcript, cleaned_text, audio_backup_path }` via the Custom Directory module.- Provide **Undo AI Edit / Redo AI Edit** in History so users can restore `raw_transcript` without re-recording.
